USB 이음

USB 케이블 하나로 폰의 인터넷을 Windows PC에서

소개

USB 이음은 USB 케이블로 연결한 안드로이드 폰의 인터넷(모바일 데이터 또는 Wi-Fi)을 Windows PC에서 쓸 수 있게 해 주는 앱입니다. PC 프로그램을 설치하고 폰을 연결하면 자동으로 이어집니다.

  • 안드로이드 8.0 이상, USB 디버깅 사용
  • Windows 10/11 64비트 + USB Ieum PC 프로그램
